## The entry

`main.ts` writes exactly one original one-line joke about office life — 106 characters — to `/output/entry.txt`:

```text
The office Wi-Fi password changed again, and now the only thing connecting this team is shared resentment.
```

One line, nothing else. The setup is the universally familiar office
annoyance — the Wi-Fi password changing without warning — and the turn
lands in the last few words: with the network down, the only thing still
connecting the team is the resentment they share.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs as-is).
